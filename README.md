# Student Manager

This repository contains a Spring Boot student management application.

## Project Location

The main application code is located in the `student-manager/` folder.

## Overview

The project is a CRUD-based web application for managing student records. It supports adding, viewing, editing, and deleting students, and uses validation rules to ensure data quality.

## Quick Start

```bash
cd student-manager
./mvnw clean install
./mvnw spring-boot:run
```

Then open:

- http://localhost:8080/students
- http://localhost:8080/h2-console

For more details, see the application README in [student-manager/README.md](./student-manager/README.md).
